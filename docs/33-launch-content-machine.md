# Purpose

This document defines the content strategy for building awareness, trust, and demand for PianoOS.

The objective is to create an audience before launch.

---

# Core Content Philosophy

## Teach First. Sell Second.

The audience should discover PianoOS because they learned something valuable.

---

# Content Mission

Help adults believe:

"I can actually learn piano."

---

# The Content Flywheel

```
Educational Content

        ↓

Audience Trust

        ↓

Email Community

        ↓

Beta Users

        ↓

Student Stories

        ↓

More Content

```

---

# Founder-Led Content Strategy

The founder is part of the product story.

The content should document:

- The problem
- The philosophy
- The build
- The learning approach
